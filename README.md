Abijan Life

A map-first browser life simulation inspired by everyday life in Côte d’Ivoire.

Technology

* Next.js
* React
* TypeScript
* MapLibre GL JS

First milestone

Build an interactive map foundation for Grand-Bassam, then expand into a living city with homes, shops, jobs, vehicles, activities and player progression.

Development principles

* Use separate files and reusable components.
* Keep map data and gameplay features modular.
* Never expose private API keys or database service-role keys in browser code.
* Verify map-provider terms and attribution before public launch.
* Add authentication, server-side validation and secure persistence before introducing player accounts.

Roadmap

1. Interactive map foundation.
2. Grand-Bassam points of interest.
3. Clickable destinations and activity panels.
4. Customizable player home.
5. Vehicles, jobs and economy.
6. Saved progress and, later, multiplayer.
